Настоящее Согласие применяется только в тех случаях, когда обработка персональных данных на Платформе Digital Autograph осуществляется на основании согласия субъекта персональных данных. Оно оформляется отдельно от Пользовательского соглашения, Публичной оферты, Политики в отношении обработки персональных данных и иных документов.

Субъект персональных данных — авторизованный пользователь Платформы, однозначно определяемый Оператором по внутреннему идентификатору учётной записи и действующей авторизованной сессии. Согласие предоставляется в электронной форме посредством отдельного действия пользователя в интерфейсе Платформы. Молчание, бездействие и заранее установленная отметка не являются согласием.

1. Цели обработки

Пользователь даёт согласие на обработку только тех персональных данных, которые он добровольно предоставляет для следующих дополнительных целей:

1) ведение необязательных данных профиля и персонализация учётной записи, если соответствующая функция включена и данные не требуются для исполнения договора;

2) обработка обращений в поддержку и обращений по вопросам персональных данных в части сведений и материалов, добровольно сообщённых Пользователем сверх данных, обработка которых необходима для исполнения договора или требований закона;

3) направление выбранных Пользователем необязательных сервисных уведомлений по указанному им каналу связи, если для такого направления требуется согласие.

Настоящее Согласие не является согласием на получение рекламы и не используется для рекламных или маркетинговых рассылок. Для таких целей при их появлении требуется отдельное предварительное согласие.

2. Перечень персональных данных

В зависимости от выбранной Пользователем дополнительной функции могут обрабатываться:

– внутренний идентификатор Пользователя и сведения, необходимые для связи данного Согласия с его учётной записью;

– имя для отображения, псевдоним или имя пользователя, если Пользователь добровольно указывает их для непубличного профиля;

– адрес электронной почты, номер телефона или иной контакт, добровольно указанный Пользователем для обращения или выбранного сервиса;

– текст обращения, приложенные Пользователем материалы и сведения, необходимые для рассмотрения такого обращения;

– минимальные технические сведения о факте предоставления Согласия: тип и версия документа, момент предоставления, источник и контекст действия в интерфейсе.

Оператор не просит в рамках настоящего Согласия предоставлять пароль, коды подтверждения, полный номер банковской карты, CVV/CVC, специальные категории персональных данных, биометрические персональные данные либо изображение подписи, используемой для юридически значимых или банковских действий.

3. Действия с персональными данными

Оператор вправе осуществлять сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, предоставление лицам, обрабатывающим данные по поручению Оператора исключительно для указанных целей, блокирование, удаление и уничтожение персональных данных с использованием средств автоматизации и, при необходимости, без их использования.

Распространение персональных данных не допускается на основании настоящего Согласия. Если Платформа предполагает предоставить доступ к персональным данным неограниченному кругу лиц, для этого запрашивается отдельное согласие на обработку персональных данных, разрешённых субъектом для распространения.

Недоступной может быть только дополнительная функция, которая объективно требует обработки данных на основании данного Согласия.

Оператор хранит доказательство предоставления Согласия в привязке к авторизованной учётной записи: тип документа, редакцию, контрольное значение текста документа, момент предоставления, источник и контекст действия.
